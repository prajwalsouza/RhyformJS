# 3D scenes

Version 0.3.0 adds GPU-rendered 3D scenes alongside the existing 2D API. Open [the fourteen 3D studies](../examples/three.html) through a local HTTP server to see the executing code beside each animation.

## Import and describe

Serve `rhyform-3d.js` or `rhyform-3d.min.js` beside your page. Three.js and Earcut are included; the page needs no framework, separate `THREE` global, CDN, or build step. A browser with WebGL2 is required. Give the stage an explicit height.

```html
<div id="stage" style="height: 480px"></div>
<div id="controls"></div>
<script src="rhyform-3d.min.js"></script>
<script>
  const scene = rhyform.scene('#stage', { dimensions: 3 });
  const helix = { type: 'helix', radius: 1, height: 4, turns: 3 };
  const curve = scene.wave({ amplitude: .7, cycles: 3 });

  curve.draw(1);
  curve.transformTo(helix, { duration: 2 });
  curve.moveTo([1, 0, 0], 1);
  curve.rotateBy([0, 360, 0], 3);

  scene.controls('#controls');
  scene.play();
</script>
```

For a native browser module, use `import rhyform from './rhyform-3d.module.js'` in a `type="module"` script. This distribution resolves its own dependencies. The files in `src/` are development source with package imports, for use with a bundler.

For a complete mathematical scene, watch [A change of sign](../examples/story.html): seven chapters build a bowl from parabolas, change a sign, and reveal a saddle. The page includes narration, chapter navigation, replay, a text alternative, and the actual scene source.

The 3D bundle also supports `rhyform.scene('#stage')` for 2D. Choose one distribution per page. Pages that only use 2D can continue using the smaller `rhyform.min.js`; Three.js is absent from that bundle.

## Objects and time

Objects start hidden. Each instruction appends a clip to the scene timeline. Durations are seconds, positions are `[x, y, z]` (or `{x, y, z}`), Y points up, and rotations use degrees. Two coordinates imply Z = 0. Most curves and flat solids start in XY; planes and height fields span XZ.

| Instruction | Behavior |
| --- | --- |
| `object.draw(1)` | Reveal a curve along its samples, or a surface through its triangles |
| `object.show(.5)` / `hide(.5)` | Fade visibility |
| `object.transformTo(descriptor, {duration: 2})` | Morph matching samples and interpolate any supplied pose/color |
| `object.moveTo([2, 1, 0], 1)` | Animate to an absolute position |
| `object.rotateTo([0, 90, 0], 1)` | Take the shortest quaternion path to an XYZ Euler orientation |
| `object.rotateBy([0, 360, 0], 2)` | Travel through the specified local-axis turn, including full revolutions |
| `object.scaleTo(2, 1)` | Animate a positive uniform scale; a three-component scale also works |
| `object.colorTo('#d1a66f', 1)` | Animate the material color |
| `object.extrude(2, {duration: 2})` | Give a planar disk, square, polygon, or filled contour depth |
| `scene.wait(.5)` | Add a hold |
| `clip.startNextImmediately()` | Start the next authored instruction alongside this clip |

Transform, move, rotate, scale, and color use smoothstep easing. `draw` and fades progress linearly. Material opacity is controlled by show/hide, rather than alpha in a color string. Use opaque hex, comma-separated RGB/HSL, or named colors. Other CSS color forms are rejected explicitly.

Creation options include `at`, `rotation`, `scale`, `color` (or `fill`), `tags`, `wireframe`, and curve `lineWidth` in CSS pixels. A transform keeps existing position, rotation, scale, and color when its descriptor omits them. Descriptors do not create an extra visible target object. `rhyform.shapes3D.helix(options)` is an optional descriptor helper.

`scene.prepare()` compiles duration and samples the current time. `seek(seconds)`, `pause()`, `resume()`, `play()` and `onUpdate(listener)` share the same clock as 2D. `play(index)` starts at an animation index; it is not a time value. `onUpdate` returns an unsubscribe function. Scrubbing reconstructs authored state, including reverse seeks. Avoid overlapping clips that write the same property on the same object: the later authored clip wins.

`object.duplicate(options)` creates a hidden copy of the authored destination with its tags. `remove()` removes that object and its animation clips, shortening the schedule. `scene.clear()` removes objects, clips, parameters, and controls. `dispose()` also releases the renderer, canvas, and resize observer. Call it when replacing a scene.

## Curves, surfaces, and fills

| Family | Constructors / descriptor types | Main parameters |
| --- | --- | --- |
| Curves | `line`, `path`, `bezier` | `from/to`; or `points` |
| Planar curves | `circle`, `ellipse`, `spiral`, `wave` | `radius`, `radiusX/Y`; `innerRadius/turns`; `length/amplitude/cycles/phase` |
| Spatial curves | `helix`, `torusKnot` | `radius/height/turns`; `radius/tubeRadius/p/q` |
| Flat solids | `disk`, `square`, `rectangle`, `polygon` | `radius` (or `radiusX/Y`); `size`; `width/height`; `sides/radius` |
| Prisms | `cube`, `prism`, `extrusion` | `size`; `sides/radius/depth`; `shape/depth` |
| Sampled surfaces | `plane`, `waveSurface`, `saddle`, `heightField` | `x/z` ranges; `amplitude/frequency/phase`; `curvature`; `fn(x,z)` |
| Round surfaces | `sphere`, `torus`, `cylinder`, `cone` | `radius`; `radius/tubeRadius`; `radius/height` |
| Derived surfaces | `between`, `loft`, `revolve`, `tube`, `ribbon` | See helpers below |
| Filled contours | `fill` | Closed XY `boundary`, optional `holes` |

Custom functions accept the mathematical parameters you specify:

```js
const curve = scene.curve(t => [Math.cos(t), t / 3, Math.sin(t)], {
  range: [0, 6 * Math.PI], segments: 300
});
const surface = scene.surface((u, v) => [u, Math.sin(u) * Math.cos(v), v], {
  u: [-2, 2], v: [-2, 2], uSegments: 64, vSegments: 32
});
const terrain = scene.heightField({ fn: (x, z) => .4 * Math.cos(x * z) });
```

The functions must return finite values and be deterministic. A path uses piecewise linear interpolation through its points. A Bézier accepts 2–32 control points. Functions and descriptors are local trusted authoring code, not a natural-language interpreter.

Derived helpers accept curve descriptors or existing curve objects. Existing objects are sampled at their **authored destination pose**, not their current playback frame. These constructions are snapshots; changing an input object later does not bind its dependents automatically.

```js
const lower = { type: 'wave', at: [0, -1, 0] };
const upper = { type: 'wave', amplitude: .4, at: [0, 1, 1] };
const sheet = scene.fillBetween(lower, upper);
const loft = scene.loft([lower, upper, { type: 'circle', at: [0, 2, 0] }]);
const tube = scene.tube({ type: 'helix' }, { radius: .12 });
const ribbon = scene.ribbon(lower, { width: .4, normal: [0, 0, 1] });
const vase = scene.revolve({
  type: 'bezier', points: [[0, -1.5], [2.8, -1.5], [.3, 1], [1, 1.5]]
});
```

A fill between curves connects matching parameter values. A loft interpolates linearly between successive cross-sections; align their direction and start points deliberately. Revolution rotates an XY profile with non-negative X around Y; its `angle` is in radians. Tubes use transported frames around a nonstationary spine. A ribbon uses a fixed reference normal, which must not be parallel to its tangent. Cylinders, cones, tubes, and revolutions are surface sweeps without automatic end caps.

Closed planar fills preserve holes during extrusion:

```js
const ring = scene.fill({ type: 'circle', radius: 1.8 }, {
  holes: [{ type: 'circle', radius: .9 }], color: '#cca776'
});
ring.draw(1);
ring.extrude(.8, { duration: 2 });
```

Use simple, nonintersecting contours; holes must be disjoint and strictly inside the outer boundary. Self-intersections, overlapping/outside holes, arbitrary SVG winding rules, and boolean operations are not validated or repaired. Flat fill/extrusion is currently restricted to XY. Use the object's pose to place it in space.

## Tag trees and assembly

Tags are slash-separated paths. A parent selects its descendants, once per object, in creation order. An object can have multiple tags. `scene.tags.tree()` returns names, paths, children, and unique descendant counts. A selection is live when inspected; an instruction captures its members when authored.

```js
scene.line({ at: [-2, 0, 0] }).tag('lesson/curves/first');
scene.wave({ at: [2, 0, 0] }).tag('lesson/curves/second');

const curves = scene.tag('lesson/curves');
curves.draw({ duration: 1, order: 'sequential' });
curves.transformTo({ type: 'helix', turns: 3 }, { duration: 2 });
curves.moveTo([0, 1, 0], { duration: 1 });
```

You can also call `scene.group('lesson/curves', [first, second])`, `scene.all()`, or `selection.addTag(path)`. Selection `draw`, `show`, `hide`, `moveTo`, and `transformTo` run together by default. Set `order: 'sequential'` for consecutive clips, or `stagger: .2` for offset simultaneous clips. Stagger is ignored for sequential order. `duration` applies to each member. Moving a group translates the centroid of its object origins to the destination, preserving their offsets.

A group transforming to one descriptor uses an explicit assembly recipe:

- Curves → curve: divide the target parameter range into adjacent sections.
- Sampled surfaces → sampled surface: divide the target U range into adjacent bands.
- Six sampled surfaces → cube: assign faces in **creation order: right, left, top, bottom, front, back**.
- `selection.transformTo([targetA, targetB], options)` maps one explicit target to each member.

Tags select the pieces; tag names do not infer geometric roles. Pieces keep their identities, colors (unless a target color is supplied), and tags. The result is an assembled visual form, not a welded mesh. Unsupported mappings fail before modifying any member's authored schedule.

## What can transform into what?

Curve morphs need equal `segments` (default 256). Surface morphs need equal `uSegments/vSegments` (default 64/32). A surface grid can become another surface grid, including a custom parametric surface. Morphs interpolate corresponding samples, rather than fading between endpoint objects.

Filled disks, squares, rectangles, and cubes share a boundary representation with 192 default samples. Square/rectangle samples must be divisible by eight to preserve corners. Polygon samples must divide evenly into its sides; the default rounds up accordingly. To morph between these families, supply an equal, compatible sample count. Hole-bearing fills can extrude without changing cap connectivity; two arbitrary fills can morph only when their triangulation matches exactly.

A line has no surface, so turning it into a solid needs a construction: tube, ribbon, revolve, fill, or extrusion. There is no universal curve-to-mesh morph, automatic algebraic meaning, arbitrary topology repair, or split/merge solver. These constraints keep transitions reproducible and inspectable.

## Equations and SVG in space

Load MathJax's SVG output before using equations. MathJax is optional and is not bundled; geometry scenes work without it. For example, load `https://cdn.jsdelivr.net/npm/mathjax@3.2.2/es5/tex-svg.js` (or serve the same file locally). Run awaited authoring code inside an async function or a module script.

```js
const equation = await scene.equation(String.raw`(x+1)^2=x^2+2x+1`, {
  width: 5.8, depth: .16, at: [0, 1, 0], color: '#4a887f'
});
equation.draw(2);
equation.rotateTo([10, -25, 0], 1);
await equation.transformTo(String.raw`x^2+2x=(x+1)^2-1`, { duration: 3 });
```

These are filled triangle meshes made from vector glyph outlines, with front, back, and side walls when `depth > 0`. They occupy the scene's XYZ space, share depth testing with other objects, and respond to camera motion. There is no rasterization, Potrace tracing, image texture, or DOM overlay for the equation. The object uses one uniform color; SVG path colors are not preserved separately.

Equation-to-equation morphs reuse structural matching by glyph, mathematical role, shape, and location. Matched symbols move/reshape; unmatched glyphs shrink toward or grow from a related location. The returned clip exposes `strategy` and `correspondence`. This is a visual heuristic, not an algebra solver; authors supply each expression and the corresponding geometry.

`await scene.equationDescriptor(tex, options)` prepares a reusable destination without creating another object. A string passed to an equation object's `transformTo` means LaTeX and returns a promise; a prepared descriptor transforms synchronously. Await asynchronous authoring before starting playback. Clearing or disposing a scene cancels its outstanding equation loads.

A one-contour glyph can also become a filled shape with corresponding contour topology:

```js
const symbol = await scene.equation(String.raw`\pi`, { width: 2.7, depth: .3 });
symbol.draw(1);
symbol.transformTo({ type: 'disk', radius: 1.5, depth: .3 }, { duration: 2 });
symbol.transformTo({ type: 'cube', size: 2.4 }, { duration: 2 });
```

`scene.svg(markup, {width: 4, depth: .2, color: '#70a69c'})` imports the same supported geometric SVG subset as 2D, with extra restrictions: paths must be closed, opaque fills without visible strokes. Convert strokes to outlines first. Holes are triangulated using SVG nonzero/evenodd winding. A vector object's `extrude(depth, options)` animates its thickness. General many-glyph-to-solid mappings are not automatic, and incompatible contours throw rather than dissolve. Live vector factories are not supported.

During equation contour morphs, changed outlines are triangulated on the CPU and uploaded to GPU buffers. Endpoints and unchanging geometry are cached by the scene; long expressions have greater CPU cost than fixed surface grids. The implementation avoids tracing, but it does not promise GPU-only text morphing or a frame-rate guarantee.

## Controls and camera

Interactive geometry is optional:

```js
const amplitude = scene.parameter('Amplitude', {
  value: .6, min: 0, max: 1.2, step: .05
});
const sheet = scene.liveShape(() => ({
  type: 'waveSurface', amplitude: amplitude.value, phase: scene.currentTime
}));
sheet.show(0);
scene.wait(6);
scene.controls('#controls');
```

Factories are reevaluated on parameter and clock updates. They must keep geometry topology fixed and only read parameters; a rejected parameter edit restores its previous value. A live object's factory owns its geometry, so use parameters to change it; `transformTo` is unavailable for live objects. Pose/color instructions still work. `scene.slider('#controls')` creates just the progress slider. `scene.controls('#controls', {playback: false})` creates parameter inputs without playback buttons.

The default camera is orthographic. Scene options include `viewHeight`, `projection: 'perspective'`, `camera: {at, lookAt}`, `background`, `description` (accessible canvas label), and `pixelRatio` (a cap, default 2). `scene.camera.moveTo(position, seconds)` animates position. `scene.camera.lookAt(point)` changes the target immediately. Camera moves are straight paths; avoid passing through the look-at point. `scene.project([x,y,z])` returns canvas-relative CSS pixels `{x,y,depth,visible}`; visible means inside the camera frustum, not unoccluded.

Paused scenes render on changes and resize, without an idle animation loop. Playback samples geometry on the CPU and renders it through Three.js WebGL; this is not GPU-only morph computation. No pointer, hover, raycasting, or orbit-control layer is installed. Object click/hover handlers and their lazy picking layer remain future work. Native controls already work without that layer.

## Scope and validation

The initial 3D engine includes the named geometry above, deterministic playback, parametric fills, tags, assembly, vector equations, filled SVG input, and native controls. It does not export SVG or video, import arbitrary meshes, or provide WebGPU. Existing SVG/equation animation remains available through 2D scenes.

Run `npm test` to build and run geometry, 2D browser, and 3D browser regressions. `TEST_BROWSER=webkit npm test` or `TEST_BROWSER=firefox npm test` selects another installed Playwright browser. Use `npm run check:release` to verify generated distributions, version consistency, private-file exclusions, and embedded license notices. Passing local tests is not a published release or a performance benchmark.
